## B. Likely viva questions

| Question | Answer |
|---|---|
| Why use a database instead of a dictionary? | A dictionary lives in RAM and is lost on restart. SQLite writes to a file (`students.db`), so the data is permanent. |
| What is SQLite? | A serverless, file-based relational database. Python supports it out of the box through `sqlite3`. |
| What is an ORM / SQLAlchemy? | An Object Relational Mapper. Python classes map to tables and objects map to rows, so we write `db.query(StudentDB)` instead of raw SQL. |
| What is `create_engine`? | It creates the connection to the database using the URL `sqlite:///./students.db`. |
| Why `check_same_thread=False`? | FastAPI can handle a request on a different thread from the one that created the connection, and SQLite blocks that by default. |
| What is `SessionLocal` / a session? | A unit of work with the database. It tracks objects and sends changes on `commit()`. |
| What does `get_db()` with `yield` do? | It opens one session per request, gives it to the endpoint through `Depends`, and always closes it in `finally`. |
| What is `Depends`? | FastAPI dependency injection, which supplies the endpoint with a database session automatically. |
| What does `Base.metadata.create_all()` do? | It creates the `students` table if it does not already exist. |
| What do `commit()` and `refresh()` do? | `commit` saves the changes permanently. `refresh` reloads the object from the database, for example to get the generated id. |
| What is a primary key? | A column that uniquely identifies each row; here, `id`. |
| What is `from_attributes=True`? | It lets Pydantic build the JSON response directly from a SQLAlchemy object. |
| What are StudentCreate, StudentUpdate and StudentResponse? | StudentCreate is the input for POST and PUT (all fields required). StudentUpdate is the input for PATCH (all fields optional). StudentResponse is the output, including the id. |
| How did you build Task 7? | `GET /students/department/{department}` filters with `func.lower(StudentDB.department) == department.lower()`, so it is case-insensitive. It returns 404 if no student matches. |
| What SQL does each endpoint run? | SELECT, SELECT ... WHERE id, INSERT, UPDATE, UPDATE (only some fields), DELETE. |
| How would you switch to MySQL? | `pip install pymysql`, then change `DATABASE_URL` to `mysql+pymysql://root:pwd@localhost:3306/student_db`. The endpoints stay the same. |
| How does SQLite compare with MySQL? | SQLite is a single file with no server, good for learning and small apps, with limited concurrent writes. MySQL is a client-server database built for many users. |
